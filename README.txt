MEMECOIN website
================
Files: index.html, assets/logo.jpg (logo + favicon), assets/banner.jpg (hero title)

Run locally: open index.html in a browser (or: python3 -m http.server).
Deploy: drag this folder into Vercel, Netlify or Cloudflare Pages, or push to GitHub Pages. No build step.

Edit:
- Contract addresses and links: search index.html for 0x19993B3C and FT6bnAW3.
- X profile: https://x.com/memecoinx4  |  Community: https://x.com/i/communities/2027140136635441349
- Colors: CSS variables at the top of the <style> block (--sky*, --gold, --cyan, --coral).
- Fonts load from Google Fonts (Pixelify Sans, Sora); the page falls back to system fonts offline.
